# Coffee World

موقع من ثلاث مراحل لعالم القهوة:

1. **ابتكر وصفتك** — اختر نوع القهوة وحدّد مقادير الحليب والإسبريسو والماء والثلج والبومب، ثم اعرض الكوب والوصفة الورقية للبريستا مع خيار الحفظ.
2. **سوق القهوة** — إعلانات مخصصة للقهوة ومستلزماتها (صور + رقم تواصل + واتساب).
3. **سِيَر البريستا** — ملفات تعريفية للبريستا الباحثين عن عمل (صورة، مهارات، سيرة).

## التشغيل محلياً

الموقع ثابت (HTML/CSS/JS فقط). افتح `index.html` مباشرة، أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8080
# ثم افتح http://localhost:8080
```

## الربط مع الواجهة الخلفية (API)

كل استدعاءات الشبكة تمر عبر `assets/js/api.js`. لربط backend:

1. افتح `assets/js/api.js` وعدّل:
   ```js
   const CONFIG = {
     API_BASE_URL: "https://api.example.com",
     API_TOKEN:    "...",         // اختياري
     TIMEOUT_MS:   15000,
   };
   ```
2. الخدمات المتوقعة من الخادم:
   - `GET/POST/DELETE /recipes`
   - `GET/POST/DELETE /listings` (+ `POST /uploads`)
   - `GET/POST/DELETE /baristas` (+ `POST /uploads`)

عندما يكون `API_BASE_URL` فارغاً، يعمل الموقع تلقائياً باستخدام `localStorage` حتى تجهز الخدمة الخلفية.

## البنية

```
├── index.html                 # الصفحة الرئيسية
├── pages/
│   ├── recipe.html            # المرحلة 1: بناء الوصفة
│   ├── cup.html               # المرحلة 1: عرض الكوب + الوصفة للبريستا
│   ├── marketplace.html       # المرحلة 2: سوق القهوة
│   └── baristas.html          # المرحلة 3: سِيَر البريستا
└── assets/
    ├── css/main.css           # كل التنسيقات
    └── js/
        ├── api.js             # طبقة الـ API (جاهزة للربط)
        ├── app.js             # أدوات واجهة مشتركة
        ├── recipe-data.js     # بيانات أنواع القهوة والتسميات
        ├── recipe.js          # منطق المرحلة 1 (البناء)
        ├── cup.js             # منطق المرحلة 1 (العرض)
        ├── marketplace.js     # منطق المرحلة 2
        └── baristas.js        # منطق المرحلة 3
```
