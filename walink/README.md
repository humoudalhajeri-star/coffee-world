# walink — مساعد طلبات لتجّار واتساب

البائع يرسل رابط كتالوج ← الزبون يختار منتجًا ويكتب بياناته ← **الطلب يُحفظ في قاعدة البيانات** ← يفتح واتساب (`wa.me?text=`) برسالة طلب جاهزة لرقم المتجر ← البائع يكمل الدفع في نفس الشات ويحدّث الحالة من لوحته.

لا WhatsApp Business API، لا بوابة دفع، لا تطبيق.

## الصفحات
| المسار | الوصف |
|---|---|
| `/` | لاندنق + روابط الدخول |
| `/b/:shop` | كتالوج المشتري + نموذج الطلب |
| `/s/:shop` | لوحة البائع (محمية بكلمة مرور): رابط المشاركة، الطلبات، المنتجات، الإعدادات |
| `/admin` | لوحة الأدمن (محمية بـ `OWNER_PASS`) |
| `/signup` · `/login` | تسجيل متجر جديد (تجريبي) / دخول البائع بالإيميل |
| `/healthz` | فحص الصحة |

اللغة: عربي RTL افتراضيًا، إنجليزي LTR، زر تبديل في كل صفحة ويُحفظ في cookie. رسالة واتساب تتبع لغة الزبون، ورسالة «واتساب العميل» تتبع لغة البائع.

## التقنية
Node.js 22.13+ · Express · SQLite (`node:sqlite` مدمج — بدون build native) على قرص دائم `DATA_DIR` · HTML مُولّد من الخادم + CSS/JS خفيف. الروابط تُبنى من `Host` الطلب (مع `trust proxy`) فتشتغل على أي دومين.

الأمان: كلمات مرور scrypt، جلسات في قاعدة البيانات (HttpOnly, SameSite=Lax, Secure على HTTPS)، رفض POST من origin مختلف، تحديد معدل لتسجيل الدخول والطلبات، escaping لكل المدخلات.

## متغيرات البيئة
| المتغير | الافتراضي | الوصف |
|---|---|---|
| `OWNER_PASS` | (مطلوب) | كلمة مرور الأدمن. لو غاب يُولَّد مؤقتًا ويُطبع في اللوج |
| `PORT` | `3000` | منفذ HTTP |
| `DATA_DIR` | `./data` | مجلد ملف `walink.db` — **لازم يكون قرص دائم** |
| `SEED_SHOP` | `demo` | متجر جاهز يُنشأ في أول تشغيل (`none` لتعطيله) |
| `SEED_SHOP_PASS` | = `OWNER_PASS` | كلمة مرور بائع المتجر الجاهز |
| `SEED_SHOP_WHATSAPP` | `96500000000` | رقم واتساب المتجر الجاهز (غيّره من الإعدادات) |

## تشغيل محلي
```bash
cd walink && npm install
OWNER_PASS=changeme npm start      # http://localhost:3000
npm test                           # اختبار end-to-end لكل المسارات
```

## النشر
### Render (موصى به — ملف `render.yaml` في جذر الريبو)
1. Render → **New + → Blueprint** → اختر هذا الريبو والفرع.
2. أدخل `OWNER_PASS` عند الطلب → **Apply**.
3. خلال دقائق: `https://walink-xxxx.onrender.com`.
> الخطة `starter` لأن القرص الدائم (`/var/data`) يتطلب خطة مدفوعة. الخطة المجانية تمسح SQLite مع كل إعادة تشغيل.

### Railway
New Project → Deploy from GitHub → Root Directory = `walink` (يستخدم الـ Dockerfile) → Add Volume على `/data` → Variables: `OWNER_PASS`, `DATA_DIR=/data` → Generate Domain.

### Fly.io
```bash
cd walink
fly launch --copy-config --no-deploy --name walink-<anything>
fly volumes create walink_data --size 1
fly secrets set OWNER_PASS='your-strong-pass'
fly deploy
```

## الاستخدام السريع
1. **إنشاء متجر:** من `/admin` ← «إنشاء متجر وربط إيميل» (تظهر كلمة مرور البائع مرة واحدة)، أو البائع نفسه من `/signup`.
2. **إضافة منتجات:** `/s/<shop>` ← تبويب «المنتجات» ← اسم/سعر/ملاحظة/صورة ← حفظ. ومن «الإعدادات» ضع رقم واتساب المتجر مع رمز الدولة.
3. **إرسال الرابط:** انسخ «رابط الكتالوج للمشاركة» (`/b/<shop>`) وأرسله للزبون في واتساب أو انستقرام. أي منتج ممكن يتربط مباشرة بـ `/b/<shop>?p=<id>`.
4. الطلب يظهر في تبويب «الطلبات» ← «واتساب العميل» للمتابعة ← بعد الدفع «تم التنفيذ».
